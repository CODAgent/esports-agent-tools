# Schedule maker for leagues

Thank you to Kevin Rotz for providing me with a working version of this script.

This schedule maker will take a list of teams and create ```M``` matches per week per team for ```W``` total weeks.  It will do so with as many unique match ups as possible.

Detailed instructions are coming soon.  For now, structure the ```input/inputFile.csv``` file similar to how the one that lives in the repo is structured.  Then run:

```
python matches.py
```

This will prompt you for a path to the input CSV file and then the path that you want the output file to be written to.  After this, the script should run.
